# M4CR0Pad MeowPad

Утилита Windows 11 и прошивка Vial-QMK для Ergohaven M4CR0Pad v1 с OLED.

- [Музыкальная сборка для Windows x64](builds/Meowpad-Media-Windows11-x64.zip) · [инструкция](Музыкальный%20режим.txt)
- [Сборка с общей громкостью и выбором аудиовыхода для x64 и ARM64](builds/Meowpad-Volume-Tray-Windows11.zip) · [инструкция](Как%20запустить.txt)

В музыкальной сборке слой Main управляет общей громкостью. MUSIC показывает название и прогресс трека Spotify, управляет воспроизведением и громкостью Spotify в микшере Windows. Apps управляет громкостью активного приложения на основном аудиовыходе. Статус сохранения трека в Spotify пока недоступен.

Перед обновлением прошивки экспортируйте раскладку и макросы из Entropy. Предыдущий рабочий UF2 входит в музыкальный комплект.

Исходники утилиты находятся в [windows](windows), патчи Vial-QMK и тест индикатора — в [firmware](firmware). Базовая ревизия Ergohaven Vial-QMK — `cf8ddff2559c176546f8071e9d799e2c693d6947`, цель сборки — `ergohaven/macropad:v1`.
